# 🎯 QuizNexus

A modern and interactive quiz application designed to provide a simple and engaging quiz experience.

## 🌐 Live Demo

[Visit QuizNexus](https://shabbir295.github.io/Quiz-Nexus/)

## ✨ Features

* 🔐 User Login & Signup
* 📝 Interactive Quiz System
* 📊 Quiz Results
* 👤 User Profile
* ⚙️ Settings
* 💾 Local Storage Data Management
* 📱 Responsive User Interface
* 🎨 Modern and User-Friendly Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* Git & GitHub
* GitHub Pages

## 💾 Data Storage

QuizNexus currently uses **Browser Local Storage** to save application data.

This means the data is stored locally in the user's browser and is not stored on a remote database.

## 🚀 Getting Started

You can use QuizNexus directly through the live website:

**https://shabbir295.github.io/Quiz-Nexus/**

Or run the project locally:

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
